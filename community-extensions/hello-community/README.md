# Hello Community (non-installable example)

This standalone JavaScript example illustrates a community extension submission. It uses **only fictional data**. It does not import Hubzam Works™ code or access the network, customer data, or private APIs. The manifest's requested permissions are declarations only and **not** supported product permissions.

Run with Node.js 20+:
```sh
node src/hello.mjs
node --test tests/hello.test.mjs
```

This directory is a format example, **not an approved or installable plugin**.
