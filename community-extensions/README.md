# Community Extension Workspace (Proposal)

Build **standalone, independently licensed projects** here, using synthetic test data and public documentation only. This is not Hubzam Works™' private application code and these contributions are not executable plugins in the live product.

Use `community-extensions/<project-id>/` with a README, `extension.json`, license, source and tests. Open a proposal issue before submitting unfamiliar project categories. See [draft submission specification](../docs/13-extension-specification.md).

Code in this directory is **unreviewed community material unless explicitly marked otherwise**. A merged pull request is not a certification, a marketplace approval, a deployment, an endorsement, or a grant of production access. No automated sync or installation into private systems exists.
