# Glossary

[Back to the Developer Hub](../README.md)

| Term | Meaning |
|---|---|
| Tenant | A business data/access boundary, such as a company or linked studio |
| Location | An operational place within a business context |
| Role | An authorization category; its meaning depends on scope and operation |
| Session | A bounded authenticated interaction represented by a credential |
| POS operator | The staff member operating a register, which can differ from the account hosting the browser session |
| Variant | A selectable version of a parent product |
| Order line | A particular purchased item/variant with its transaction context |
| Tender | The payment method or payment allocation used for a transaction |
| Fulfillment | Work needed to deliver or complete the purchased offering |
| Rental copy | A specific physical rentable item, distinct from its catalog title |
| Entitlement | A customer/member eligibility or usage allowance |
| Public representation | Fields intentionally suitable for a public audience |
| API | An interface through which software requests information or operations |
| Bearer token | A credential whose possession is used to authenticate a request |
| Webhook | An external provider's event callback to an application |
| Local-first | A design using device-local state for supported workflows with later synchronization |
| OPFS | Origin Private File System, a browser storage capability |
| SQLite WASM | SQLite running through WebAssembly in the browser |
| Service worker | A browser background component supporting features such as request caching |
| Reconciliation | Evaluating pending changes against accepted shared state |
| Conflict | A change that cannot be accepted as submitted without additional handling |
| Revision | A way to distinguish different accepted versions of a record |
| Idempotency | A contract under which repeating the same operation does not create an unintended duplicate effect |
| Provider boundary | The separation between Hubzam and an external service such as a payment processor |
| Proprietary implementation | Private code, formulas, schemas, and operating details not distributed by this repository |
