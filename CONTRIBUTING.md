# Contributing to the Developer Hub

Thank you for helping make Hubzam Works™ easier to understand.

## What belongs here

Documentation corrections, clearer explanations, accessibility feedback about published materials, integration proposals, and synthetic examples belong in this public repository. Keep proposals focused on an observable problem and the behavior users need.

Application source, private schemas, customer exports, deployment scripts, credentials, proprietary formulas, and security exploit details do not belong here.

## Documentation pull requests

1. Check the relevant guide and distinguish observed behavior from a proposal.
2. Make a focused documentation change.
3. Use fictional records and placeholder credentials only.
4. Check links, tables, JSON examples, and any Mermaid diagrams.
5. Explain the change, its evidence, and any remaining uncertainty in the pull request.

Maintainers review contributions before merging. Production application changes require separate private access, review, and an authorized release; merging public documentation does not deploy software.

## Integration proposals

Describe the business use case, the intended audience, the minimum data required, the actions needed, tenant boundaries, failure handling, and how you would test without real customer data.

Do not request unrestricted database access or a shared administrator account. No public SDK or marketplace enrollment is implied by submitting a proposal.

## Public issues

Remove private identifiers, browser/session tokens, request headers containing credentials, personal information, and identifiable receipts from reports. Provide a minimal fictional example and explain the expected and observed behavior.

Use [SECURITY.md](SECURITY.md) for security-sensitive reports.

## Review standards

Documentation should be accurate, understandable, and specific about limitations. Avoid certification claims, legal promises, version guarantees, implementation details, and provider availability claims that have not been approved and substantiated.

By contributing here, do not assume you have received a license to Hubzam Works application source, brands, customer data, or proprietary technology. See [NOTICE.md](NOTICE.md).
